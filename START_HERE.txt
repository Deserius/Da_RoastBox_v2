DA ROASTBOX - START HERE
=========================

1. Extract the whole ZIP into a local folder (e.g. C:\RoastBox on Windows).
   Don't run it from inside the ZIP viewer, and avoid very long/nested paths.

2. Set your API keys (OpenAI, OpenRouter, ElevenLabs, Stripe, Google sign-in):

        python install.py

   This opens a small window. Paste each key, press Verify to check it for
   real against that provider, then Save. It writes straight into
   backend\.env, which stays on your machine and persists across restarts.
   You can skip this step and come back to it later; the app runs in a
   limited local demo mode without any keys.

3. Start the app:

        Windows:        double-click RUN.bat   (or: python server.py)
        macOS / Linux:  ./run.sh                (or: python3 server.py)

   The first run creates a Python virtual environment and installs the
   backend packages (a couple of minutes). After that, starting is instant.
   server.py checks what it needs, starts the server, and opens the app in
   your default browser automatically.

WHAT YOU DO *NOT* NEED
- No MongoDB. The database is built in (see backend/local_storage/) and
  needs nothing installed or running. Point MONGO_URL at a real MongoDB or
  Atlas connection string in backend\.env only if you specifically want one.
- No Node.js or Yarn. The frontend ships prebuilt (frontend/build) and is
  served by the same Python process as the API. Node/Yarn are only needed if
  you want to edit the frontend's source code and rebuild it - see
  setup.bat / setup.sh for that, which is optional.

WHAT YOU DO NEED
- Python 3.11, 3.12, 3.13, or 3.14 (from https://python.org - tick "Add
  python.exe to PATH" on Windows).

SETTINGS CONSOLE
Once the app is running, its in-app Settings page (for managing keys and
model choices from the browser instead of install.py) is behind a passphrase:

        roastbox

KEEP YOUR DATA
backend\.env and backend\local_storage\ hold your keys and your database.
They are never deleted or overwritten by re-running RUN.bat/run.sh/install.py.
